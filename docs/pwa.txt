Att skapa en service-worker som underlättar att göra appen offline och ladda filerna lokalt istället och i första hand:
  https://web.dev/learn/pwa/service-workers
    -js-filen ska ligga i roten eftersom den har kontroll över filerna i katalogen den ligger i, och dess underkataloger.
    -Den enklaste ser ut så här, och ser till att _ingenting_ laddas, men allt hamnar fint i loggen. :)
      self.addEventListener("fetch", event => {
          console.log(`URL requested: ${event.request.url}`);
      });
    -Mer här: https://web.dev/learn/pwa/serving
    
    self.addEventListener("fetch", event => {
        const response = .... // a response or a Promise of response
        event.respondWith(response);
    });
    <-respondWith() interceptar ett fetch-event och låter mig göra saker där. Ifall du inte gör en respondWith() för en specifik fetch, så går browsern automagiskt vidare och laddar resursen online.
    
    return caches.match(event.request)
      <-Letar i cachen efter den requestade filen. Kompakt och fint. :)
      
    return cachedResponse || fetch(event.request);
      <-Om jag kan tolka det hela rätt, så returneras cachedResponse om den inte är null, annars körs fetch() och det värdet returneras.
    
  https://web.dev/learn/pwa/caching
    Caution: The Cache Storage API doesn't update your assets if you change them on your server nor does it delete them. 
    -Det är upp till dig att kolla om din app kör en äldre version, tex. genom att alltid ladda en liten textfil med versionsnr i och aldrig cacha den. :)
    -Om äldre, uppdatera själv. Se mer här:
      https://developer.mozilla.org/en-US/docs/Web/API/Cache
      Jag antar att man kan köra 
      Cache.delete()
      och sedan 
      Cache.add()
      för att ladda senaste versionen av en fil. 
      ..enklast möjliga versionshantering slänger samtliga cachade filer, och kör sedan addAll() eller vad den heter. 

      // Här drar den ner alla filerna en enda gång, vid install eventet. Det är sub-optimalt eftersom om man stänger tabben så körs "install" eventet igen när man åter öppnar sidan. Antar att det kan gälla för pwa också, tex om spelaren dödar spelet.
      const urlsToCache = ["/", "app.js", "styles.css", "logo.svg"];
      self.addEventListener("install", event => {
         event.waitUntil(
            caches.open("pwa-assets")
            .then(cache => {
               return cache.addAll(urlsToCache);
            });
         );
      });
